Knowledge base over incident investigations

2026 · In design

A local search layer so an AI assistant can find precedents across nearly 90 documented incident investigations, instead of reading whole files or grepping by hand.

Designed together with Claude (Anthropic), with security as a requirement: a local full-text index (SQLite FTS5, BM25 ranking) kept out of version control, metadata only for the heavy evidence (about 5.4 GB), and compact results that are treated as leads and verified against the source file before being cited. Semantic search with embeddings is planned for when keyword search proves insufficient.

Automated DEV database environments on Azure

2026

Automation with Terraform, Bash and Python that creates, for each Jira ticket, an isolated database environment on Azure, so each developer can work with production-like data without colliding with the shared development resources.

A single command restores 4 Azure SQL databases and 2 CosmosDB accounts from the shared development environment, and writes 34 Azure App Configuration keys per developer. Authentication uses a managed identity, with no service principal secrets on the server.

Another command tears the environment down in dependency order and records what was removed. An HTML report shows active and deleted environments per ticket and per developer, and every successful provisioning notifies the developer through a Google Chat webhook.

  • Terraform
  • Azure SQL
  • CosmosDB
  • Azure App Configuration
  • Bash
  • Python
  • Google Chat webhooks
